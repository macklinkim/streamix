# 가입 승인 운영

새로 가입한 비밀번호·Twitch 계정은 `approved_at = NULL`로 생성된다. 승인 전에는 로그인 세션을 발급하지 않는다. 마이그레이션 `0004_useful_shotgun`은 기존 사용자를 승인 상태로 유지한다.

배포 순서:

1. 데이터베이스 백업 후 `pnpm --filter @streamix/db db:migrate`를 실행한다.
2. Core, BFF, Web을 같은 버전으로 배포한다. 마이그레이션 전에 새 Core를 기동하지 않는다.
3. 운영자가 `ADMIN_EMAIL=kopsert@naver.com`, `ADMIN_PASSWORD`, `DATABASE_URL`을 실행 환경에 일시적으로 지정하고 `pnpm --filter @streamix/svc-core admin:bootstrap`을 한 번 실행한다. 비밀번호는 8~200자이며 영문, 숫자, 특수문자를 각각 1개 이상 포함해야 한다. 흔한 문자열은 거부된다. 기존 동일 이메일 계정이 있으면 명령은 아무 계정도 바꾸지 않고 실패한다. 기존 세션이 관리자 권한을 이어받지 못하게 하기 위한 제한이다. 비밀번호를 소스, 채팅, 셸 기록에 적지 말고 실행 직후 환경 변수를 제거한다.
4. 해당 계정으로 로그인하여 `/admin`에서 대기 중인 가입 신청을 승인한다.

관리자 화면에서 보이는 권한은 편의 기능이다. 실제 목록 조회·승인 권한은 Core가 사용자 ID로 다시 검사한다. 가입 신청자는 승인 결과를 별도 알림으로 받지 않으므로, 승인 후 다시 로그인해야 한다.
