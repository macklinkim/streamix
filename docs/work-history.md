## 2026-10-20 — 인증·랜딩·방송실 변경 배포 (이전 작업 기록)

아래 내용은 이번 리뷰에서 다시 배포한 결과가 아니라 [기존 릴리스 기록](../outbox/releases/2026-10-20-ca2551c3.md)에 근거한 이관 요약이다.

- 회원가입 진입 버튼과 로그인 수준의 둘러보기 버튼 추가. 랜딩 표시를 로컬 자정까지 하루 한 번으로 제한.
- 로그인 두 화면에 이메일 저장과 자동 로그인 선택 추가. 비밀번호는 저장하지 않으며 세션 쿠키 지속 여부는 서버가 처리.
- 중복 가입 DB 오류 래핑을 처리하여 중복 이메일에 HTTP 409 반환.
- `/studio`의 설정과 `/studio/live`의 송출·실시간 채팅·시청자 채팅 관리 분리. 내 방송 보기와 방송 설정은 새 탭으로 열도록 변경.
- Vercel 웹과 Fly Core/BFF/Media 배포 완료. 스키마 0004 적용과 기존 사용자 승인 상태 보존을 기록했다. Git 커밋·푸시는 수행하지 않았다.
- 당시 검증: 프로덕션 빌드, 서비스 상태, 중복 가입 409, 비로그인 채팅 관리 401, 실제 Redis 회전/로그아웃, 공개 화면 스모크. 실제 카메라 송출은 이번 배포 검증에 포함하지 않았다.
- 당시 미완료: 최초 관리자 설정. 신규 가입 승인은 관리자 설정 후 가능하며 [가입 승인 운영](signup-approval.md)을 따른다. 현재 관리자 수를 이번 리뷰에서 재조회하지 않았다.
