## 검증 범위와 한계

- `pnpm --filter @streamix/web typecheck`: 통과.
- `pnpm --filter @streamix/bff test`: 11개 통과.
- `pnpm audit --prod --audit-level=high`: 실패, Critical 2건·High 15건. 개별 권고의 실제 호출 가능성은 002 실행 때 재확인한다.
- `pnpm exec eslint apps/web --no-warn-ignored`: 생성 파일 `apps/web/next-env.d.ts`의 triple-slash 규칙 오류 1건. 웹 패키지에는 `lint` 스크립트가 없어 현재 루트 `pnpm lint` 대상에도 포함되지 않는다. 생성 파일 규칙 예외와 웹 lint 작업 추가는 별도 범위로 남긴다.
- 정적 코드 조사다. 배포 환경, 실제 방송 장비, 전체 Playwright 경로, 부하 및 성능 측정은 실행하지 않았다. 작업 트리의 기존 `CLAUDE.md`, `README.md`, `.claude/`, `AGENTS.md`, `STREAMIX-RESTART.md`, `~/` 변경은 수정하지 않았다.
